# VulnShop — Intentionally Vulnerable Demo API

> ⚠️ **WARNING**: This application contains **intentional security flaws** for research and demonstration purposes.
> It **MUST only run on localhost** (`127.0.0.1`) and **MUST NEVER be exposed to the internet**.

## Purpose

VulnShop is a small FastAPI application that mirrors real-world OWASP API Top 10 2023 vulnerabilities in a safe, controlled way. It provides **ground truth** for evaluating the AI API Testing Platform's vulnerability detection capabilities.

## Running

```bash
# Install dependencies
pip install -r requirements.txt

# Start on localhost:9000
python main.py
# OR
uvicorn main:app --host 127.0.0.1 --port 9000
```

The server will print the demo tokens on startup.

## Known Flaws

See [`GROUND_TRUTH.json`](./GROUND_TRUTH.json) for the full annotated list.

| Endpoint | OWASP Category | Flaw |
|----------|---------------|------|
| `GET /users/{id}` | API1 — BOLA | Any user reads any user's data |
| `POST /admin/reset` | API5 — BFLA | No role check |
| `PATCH /users/{id}` | API3 — BOPLA | Accepts `role` field (mass assignment) |
| `GET /products` | API4 — Resource Consumption | No pagination cap |
| `GET /debug` | API8 — Misconfiguration | Verbose internal info |
| `POST /fetch` | API7 — SSRF (simulated) | Accepts arbitrary URL |
| `POST /login` | API4 — Resource Consumption | No rate limit |

## OpenAPI

The spec is auto-generated by FastAPI at `http://localhost:9000/openapi.json`.

## Safety

The SSRF endpoint (`POST /fetch`) **never actually makes HTTP requests**. It is a simulation of the vulnerability pattern only. All flaws are designed to be harmless in isolation.
